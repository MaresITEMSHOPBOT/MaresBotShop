# ZÍTRA — kompletní koncept politického hnutí

> ⚠️ **Fiktivní koncept.** ZÍTRA je smyšlené politické hnutí vytvořené jako
> ukázka značky, grafiky a programové práce. Není registrovaným politickým
> subjektem a nezastupuje ani nenapodobuje žádnou skutečnou stranu, hnutí
> ani osobu. Čísla v materiálech jsou ilustrativní odhady konceptu.

**Claim:** *Stát, který funguje.*
**Pozice:** pragmatický střed — kompetence bez ideologie, konkrétnost bez hněvu.
**Pět pilířů:** bydlení · energie · zdraví · stát bez papírování · bezpečí.

## Obsah

| Soubor | Co v něm je |
|---|---|
| [`PROGRAM.md`](PROGRAM.md) | volební program: 10 kapitol, financování, prvních 100 dní, měřitelné cíle |
| [`STRATEGIE.md`](STRATEGIE.md) | proč koncept může uspět: mezera na trhu, cílové skupiny, message house, kampaň, rizika |
| [`BRAND.md`](BRAND.md) | manuál značky: logo, barvy, písmo, kompozice, jazyk |
| [`index.html`](index.html) | brand book — jedna stránka se vším k prohlédnutí |
| `logo/` | 8 variant loga (základní, transparentní, mono, horizontální, vertikální, favicon) |
| `grafika/` | 9 hotových šablon: plakáty A1, billboard, social, leták A5, vizitka |

## Prohlédnutí

Otevřete `index.html` v prohlížeči — načte všechny SVG z `logo/` a `grafika/`.

```bash
python3 -m http.server 8000   # a pak http://localhost:8000/strana/index.html
```

## Poznámka k formátům

Všechna grafika je vektorové SVG s živými texty (lze přepsat v editoru).
Před tiskem převeďte texty na křivky a doplňte spadávku 3 mm.
Písmo: Inter (800 / 600 / 400), náhrada Helvetica Neue / Arial.
