Use these when the Printful product prints the **whole garment**

How to use in Printful: pick the all-over-print product → for each print
area click **Upload** and drop the matching AOP file → drag to fill the
whole area (Fill) → for sleeves/hood/pocket choose the star tile with
**Pattern → Repeat**. Background is pure black `#000000` everywhere, so
all panels match seamlessly at the seams.
